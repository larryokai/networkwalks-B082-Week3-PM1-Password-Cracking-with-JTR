# networkwalks-B082-Week3-PM1-Password-Cracking-with-JTR
John the Ripper (JTR) is a popular cybersecurity tool used to test the strength of passwords by attempting to recover passwords from password hashes. It is commonly used by security professionals and system administrators during authorized password audits.
The main purpose of using JTR is to identify weak or easily guessable passwords so they can be replaced with stronger ones. It is therefore useful for penetration testing, security auditing, and learning about password security.
